# Bryce zuo 作品集网站

这是一个不依赖框架、可直接打开或部署到 GitHub Pages 的个人作品集。

## 打开方式

直接双击 `index.html` 即可浏览。为了确保 PDF 链接和本地资源读取正常，建议在作品集目录下启动一个本地服务器：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。如果从当前文件夹启动，需要先进入 `作品集网站`：

```powershell
cd "作品集网站"
python -m http.server 8000
```

## 页面结构

```text
作品集网站/
├─ index.html                   # 主页
├─ work/
│  ├─ cyber-liyuan.html         # 赛博梨园
│  ├─ heritage.html             # 硕士学位论文
│  └─ toy-radar.html            # 潮玩雷达
├─ assets/
│  ├─ styles.css                # 全站视觉与响应式样式
│  ├─ script.js                 # 导航、筛选、滚动动效
│  ├─ img/                      # 项目截图与视觉素材
│  └─ docs/                     # 对外展示的论文与项目 PDF
├─ 参考主页拆解.md               # 个人主页案例与可借鉴点
└─ 整理说明.md                   # 材料取舍与后续修改建议
```

## 当前取舍

- 主页只放 3 个能形成能力闭环的项目，不把所有原始文件平铺出来。
- 家庭运转系统及其相关文件没有进入网站，也没有被删除。
- 团队项目明确标注了个人负责范围，避免把团队成果写成个人成果。
- 潮玩雷达注明了 AI 编程工具辅助，强调产品判断与验收标准。

## 上线前建议补 3 项

1. 增加一张自然、清晰的人像，放在“关于”或页脚，不要用过度正式的证件照。
2. 补充一份 1 页 PDF 简历，并在页头或页脚放置“下载简历”链接。
3. 补充真实联系方式：邮箱优先，可同时保留 GitHub 与线上产品链接。

## 部署到 GitHub Pages

1. 新建仓库并上传 `作品集网站` 中的内容到仓库根目录。
2. 打开仓库 `Settings → Pages`，将 Source 设为 `Deploy from a branch`。
3. 选择 `main` 分支和 `/ (root)`，保存后等待 GitHub 生成公开链接。
